Desktop Buddy

Firmware für das Elecrow CrowPanel 1,46″ Rotary Display · Version …

  1. Öffne diese Seite in Chrome oder Edge am Computer.
  2. Verbinde den Buddy per USB-C-Kabel.
  3. Klicke auf Installieren und wähle den Anschluss (meist „USB JTAG/serial debug unit“).
  4. Nach dem Neustart öffnet er das WLAN „Buddy-Setup“. Verbinde dich mit dem Handy und trage dein WLAN und deinen Ort ein.
Dein Browser kann leider nicht per USB flashen. Nimm Chrome oder Edge am Computer. Die Seite muss über HTTPS geöffnet werden.

Ist der Buddy schon im WLAN, braucht es kein Kabel: Knopf drücken → Menü → „Update“. Neue Versionen erscheinen hier automatisch.
